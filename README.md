# DevFolio

My personal developer portfolio, built as part of the Web Development assignment. It demonstrates responsive design using semantic HTML, a CSS color/type system, Flexbox, and CSS Grid.

## Live Demo
**Live URL:** https://Preethesh-hub.github.io/portfolie/

## Project Requirements Met
- **Semantic Structure**: Uses `<header>`, `<main>`, `<section>`, and `<footer>`.
- **CSS System**: Uses CSS Custom Properties (variables) for consistent colors and fonts.
- **Flexbox**: Used for header and navigation layout.
- **CSS Grid**: Used to layout the responsive projects section.
- **Responsiveness**: Images are fluid (`max-width: 100%`) and media queries (`@media`) are used to shift the project grid from 1 column on mobile to 3 columns on desktop.

## How to run locally
1. Clone this repository:
   ```bash
   git clone https://github.com/Preethesh-hub/portfolie.git
   ```
2. Open `index.html` in your browser.
